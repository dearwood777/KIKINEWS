Rust 1.100 Release Adds Never Type, Custom Allocators, and Cargo Enhancements▍9.0/10

hackernews · mbStavola · Nov 12, 18:39 · Discussion

Rust 1.100 stabilizes the never type and custom allocators, introduces dependency cooldowns, Cargo warnings for unused dependencies, and new APIs such as bool::toggle, Box::map, str::trim_prefix/suffix, Path::trim_prefix, and DropGuard. Cargo install now defaults to using the lockfile in the crate tarball, making --locked a no‑op.

Background

Rust 1.100 builds on the long‑term Cargo dependency cooldown feature defined in RFC 3923, which was first discussed in early 2026 and added to Cargo to delay adoption of newly published crate versions. It also finalizes the never type, a language feature that had been in development for years and was announced as stabilizing in earlier releases. These prior discussions and stabilizations set the stage for the new language and tooling changes in 1.100.

Impact

Developers can now use the never type for functions that never return, write custom allocators for fine‑grained memory control, enforce reproducible builds with dependency cooldowns, and clean Cargo.toml files by removing unused dependencies flagged by Cargo warnings.
