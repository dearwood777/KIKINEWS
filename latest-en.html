Nginx's HTTP/2 implementation contains a critical unauthenticated remote code execution flaw (CVE‑2026‑123633 and CVE‑2026‑123007) that can be triggered on any server with HTTP/2 enabled. The vulnerability affects all Nginx versions that support HTTP/2, which is not enabled by default but is used by roughly 12 % of web servers worldwide.

Background

Nginx is a widely used web server that supports HTTP/2, a protocol that improves performance by multiplexing streams over a single connection. The HTTP/2 implementation in Nginx has recently been found to contain critical integer underflow bugs (CVE‑2026‑123007 and CVE‑2026‑123633) that allow unauthenticated remote code execution when HTTP/2 is enabled.

Impact

Web servers running Nginx with HTTP/2 enabled must apply the official patch or disable HTTP/2 immediately to prevent remote code execution by unauthenticated attackers.
