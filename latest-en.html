Gemini Decisions API Launch▍8.0/10

hackernews · iamdelirium · Nov 11, 18:32 · Discussion

Google has released the Gemini Decisions API, a new interface for decision‑making models that supports text, image, audio, video, and PDF inputs, can score up to 1,000 questions in a single request, returns probability and confidence scores, and offers an end‑to‑end latency of roughly 150‑250 ms. The API is priced at $0.10 per million input tokens with no charge for output tokens, making it about five times cheaper than the Gemini 3.5 Flash‑Lite model, and is available through Google AI Studio.

Background

The Gemini Decisions API builds on Google’s Gemini family of large language models, specifically the new Gemini Decision 1 model, which was introduced as a lightweight, closed‑set decision‑making model. It extends the Gemini API by adding primitives for bounded choices such as tool selection, policy checks, model routing, and context grading, and supports multimodal inputs (text, image, audio, video, PDF) with probabilistic outputs.

Impact

Developers can now build multimodal decision systems—such as tool selection, policy checks, or model routing—at lower cost and with low latency, enabling tighter integration into production workflows.

Community Discussion

Commenters noted surprise at the timing of the release, discussed how the API’s probabilistic outputs differ from earlier grammar‑constrained approaches, and highlighted its higher cost relative to other decision models while praising its audio/video support.
