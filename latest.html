1Password Security Incident Exposes Customer Data via Malicious Code Push▍8.0/10

hackernews · lxhrstn · Nov 25, 17:18 · Discussion

1Password confirmed a November 19 intrusion in which an attacker accessed an employee's GitHub account, used it to push malicious code to the company's internal servers, and downloaded customer names and email addresses. The breach did not compromise encrypted vaults or other secrets, highlighting that code‑deployment workflows can be a critical attack vector for SaaS providers.

Background

1Password stores and shares its source code on GitHub, and the company's internal servers run code that is deployed from that repository.

Impact

Customers' publicly visible information (names and login emails) was exposed, but their encrypted password vaults remained secure. Users should verify that no vault data was accessed and consider reviewing their own code‑deployment security practices.

Community Discussion

Commenters emphasize that allowing employees to push code to production without strict branch protection is a major vulnerability, and that the incident underscores the importance of disabling direct pushes to main branches and enforcing merge rules.

中文

背景

1Password 将源代码托管在 GitHub 上，员工账户被攻击后可直接推送代码至内部部署环境。

影响

受影响的客户仅泄露了姓名和邮箱，未暴露加密密码库；但泄露的联系信息可能被用于钓鱼攻击。

社区讨论

评论者指出此类攻击凸显 SaaS 代码推送安全的重要性，建议加强分支保护和禁止自合并，以防止恶意代码被部署。

For the first time, the world recorded six consecutive days with temperatures 2 °C above preindustrial levels, confirmed by The Guardian on 25 November 2026. The record was observed globally, marking a new milestone in climate science.

Paris‑Agreement 2°C Threshold Context

The 2 °C limit is the upper bound set by the Paris Agreement to curb global warming, measured as the average surface temperature anomaly relative to the 1850‑1900 baseline. Global temperature records are compiled from satellite and surface observations, and the 2 °C threshold has been exceeded intermittently in recent years, but never for more than a few days in a row. The new six‑day streak marks the first time the anomaly has stayed above 2 °C for that duration, underscoring the growing frequency of extreme temperature events.
