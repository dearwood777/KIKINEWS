Language Models Rewrite Their Own Weights via Reasoning▍8.0/10

hackernews · lwhsiao · Nov 20, 16:29 · Discussion

A preprint on arXiv proposes that a language model can rewrite its own weights by reasoning about potential edits, a gradient‑free, no‑training self‑improvement method. The model generates candidate weight changes, tests them on practice problems, and only accepts those that improve performance, thereby iteratively refining its parameters. This approach is presented as a new weight‑space programming paradigm that could reshape how models are trained, though it remains unverified and is currently only a theoretical proposal.

Weight‑space programming background

Weight‑space programming treats a neural network's weights as a program that can be read and edited by a language model; MIT researchers demonstrated this with GPT‑6 Astra, which could read, repair, and rewrite other models' weights.

中文

语言模型可自行重写权重

一篇预印本提出语言模型可通过推理自行重写权重，采用无梯度、无训练的自我改进方法。该方法不需要反向传播或外部优化器，模型在推理过程中生成并测试权重修改，随后仅保留有效改动。此技术仍处于实验阶段，尚未公开实现或验证其性能提升。

权重空间编程概念

权重空间编程将模型的权重视为可读写的程序，允许语言模型直接读取并修改自身参数，而不依赖梯度更新。

影响

若验证成功，开发者可在不使用 GPU 训练的情况下尝试自我改进模型，可能降低训练成本并加速迭代。

社区讨论

评论者指出此方法与先前的权重空间编程相似，且实际上与传统训练过程相近，质疑其是否真正无训练。

中文

Linux 内核 KVM 的 CVE‑2026‑99312 漏洞仅影响启用嵌套虚拟化的 AMD 主机，攻击者可在虚拟机内读取约 127 GB 主机内存。该缺陷已在 11 月 18 日随稳定内核 7.3.5 及后续版本发布修复，Debian、Ubuntu 等发行版的内核尚未包含补丁，补丁到位前可通过禁用嵌套虚拟化来缓解。
