DeepMind uses AI to formally verify key parts of Signal protocol▍8.0/10

rss · Ars Technica · Nov 11, 14:08

Google DeepMind researchers applied their new AI framework AlphaProof Code to formally verify several core cryptographic guarantees of the Signal protocol, completing the proof‑of‑concept in about four weeks. The AI‑assisted analysis proved the targeted properties, found no new vulnerabilities, and correctly identified known, already‑fixed flaws in older protocol versions. The verification covers only selected components of the protocol—not the entire Signal mobile app—and the team released the specification and proof for reuse by other formal‑verification efforts.

Tags: #AI, #formal verification, #cryptography, #software security, #Signal

Formal verification and AI assistance

Formal verification uses mathematical proofs—often written in proof assistants such as Lean—to guarantee that software behaves as specified, a process that traditionally required extensive manual modeling of code and properties. Recent AI‑driven frameworks, like DeepMind’s AlphaProof Code, automate the translation of live code into Lean theorems using agentic AI, enabling much faster verification of larger codebases such as the Signal protocol. This capability builds on earlier manual efforts to verify cryptographic primitives but had not been applied at the scale of a widely deployed messaging protocol before.

Impact

By releasing the verified specification and proof, DeepMind provides a concrete artifact that other cryptographers and security engineers can build on, potentially accelerating AI‑aided formal verification of similar communication protocols.
